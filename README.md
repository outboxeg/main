# برة الصندوق – المدرسة الخضراء الذكية 🌱

## 🚀 الرفع على GitHub Pages

1. أنشئ **Repository** جديد على GitHub
2. ارفع **جميع الملفات مباشرةً** في جذر الريبو
3. من إعدادات الريبو اختر: **Settings → Pages → Deploy from main branch → / (root)**
4. انتظر دقيقتين والموقع سيعمل مباشرة
