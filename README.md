# 🌿 برة الصندوق – المدرسة الخضراء الذكية
## Bara El-Sandouq – Smart Green School Platform

> مبادرة خضراء ذكية وموثقة ميدانياً بمحافظة البحيرة لجمع وإعادة تدوير الورق والكرتون المدرسي وتحويله إلى أدوات ووسائل تعليمية مبتكرة مع تمكين المرأة وأمهات الطلاب والشمول الكامل لذوي الهمم.

### 📂 الهيكل المعماري للمستودع (Repository Architecture):
```text
outbox/
├── 📁 assets/                     # مجلد الأصول الرقمية والتصميم
│   ├── 📁 css/                   # أنظمة الألوان والتنسيق والتجاوب (styles.css)
│   ├── 📁 images/                # الشعارات الرسمية والصور التوثيقية والأنشطة
│   └── 📁 js/                    # الأكواد المجمعة وموجه الصفحات (app.js, main.js)
├── 📁 docs/                       # الوثائق المرجعية ومواصفات المشروع وأدلة المبادرة
├── 📁 pages/                      # المكونات البرمجية التفصيلية للصفحات الـ 9
├── 📁 tests/                      # حزم الاختبارات التلقائية الشاملة
├── 📁 .github/workflows/          # مسار النشر السحابي التلقائي (static.yml)
├── 📄 index.html                  # ملف الـ SPA الرئيسي للمنصة
├── 📄 README.md                   # الدليل التعريفي الشامل للمستودع
├── 📄 UPDATES.md                  # السجل المركزي الموحد لكافة التحديثات
└── 📄 .nojekyll                   # ملف ضبط وتوافق خوادم GitHub Pages
```
