# دليل مهارة هندسة تطبيقات الهواتف وتوليد ملفات الـ APK (Mobile App & Native APK Engineer)

هذه المهارة تُمكّن الوكيل الذكي من تحويل أي تطبيق ويب أو منصة برمجية إلى **تطبيق هاتف محمول متكامل (Standalone Mobile App & Native APK)** جاهز للعمل على جميع الهواتف الذكية (Android & iOS)، وتوليد ملف الـ `.apk` النهائي الجاهز للتثبيت الفوري في مجلد المشروع بنقرة واحدة.

---

## 1. الهيكلية المعمارية المعتمدة للمشروع (Directory Architecture)

عند طلب إنشاء تطبيق هاتف للمشروع، يتم إنشاء مجلد مخصص باسم `تطبيق_الهاتف/` (أو `mobile_app/`) ويحتوي على الهيكل التالي:

```text
تطبيق_الهاتف/
├── www/                                # تطبيق الويب المستقل التفاعلي (100% Offline PWA)
│   ├── index.html                      # واجهة التطبيق الرئيسية والشريط السفلي والمودال
│   ├── manifest.json                   # مانيفست تطبيق الويب
│   ├── sw.js                           # Service Worker بنظام Network-First المحدث
│   ├── css/
│   │   └── mobile.css                  # أنماط وتنسيقات الهاتف اللمسية و Action Sheet
│   ├── js/
│   │   ├── app.js                      # محرك التنقل والـ SPA Router
│   │   ├── calculators.js              # محرك الحاسبات العلمية والبيئية
│   │   └── forms-whatsapp.js           # محرك التجهيز والإرسال المباشر لواتساب
│   ├── pages/                          # صفحات المنظومة الكاملة
│   └── assets/                         # الصور، الأيقونات، المستندات
├── android/                            # مشروع أندرويد الأصلي الخالص (Pure Native Android)
│   ├── build.gradle                    # إعدادات البناء الجذرية
│   ├── settings.gradle                 # ضبط المشروع
│   ├── gradle.properties               # ضبط الذاكرة ومسارات اللغة العربية
│   └── app/
│       ├── build.gradle                # إعدادات التطبيق والتوقيع
│       ├── proguard-rules.pro          # قواعد الحماية والأمان
│       └── src/main/
│           ├── AndroidManifest.xml     # المانيفست المشدد أمنياً
│           ├── java/eg/outbox/app/
│           │   └── MainActivity.java   # كلاس النشاط الرئيسي الخالص
│           ├── res/                    # الأيقونات والألوان و network_security_config.xml
│           └── assets/www/             # نسخة متطابقة من ملفات www للتضمين الداخلي
├── simulator.html                      # محاكي تفاعلي مدمج على هيئة هاتف ذكي مع QR Code
└── [اسم_المشروع].apk                    # ملف الـ APK النهائي الجاهز للتثبيت المباشر
```

## 2. قواعد تجربة المستخدم والشريط السفلي (UX & Bottom Navigation Standard)

### أ. توزيع عناصر الشريط السفلي الخمسة:
1. **🏠 الرئيسية (`#home`):** نظرة موجزة، خفيفة، ومباشرة (أبرز 3-4 أرقام ميدانية وشريط شركاء مختصر).
2. **📊 الأثر (`#impact`):** لوحة المؤشرات الميدانية الكاملة ودليل المدارس/الجهات.
3. **🧮 الحاسبات (`#calculators` - في المنتصف كأداة تشغيلية بارزة):** حاسبة انبعاثات الكربون وحاسبة العوائد المالية بنقرة واحدة.
4. **📋 النماذج (`#forms`):** استمارات التسجيل والانضمام السريعة.
5. **🔲 المزيد (`openNavSheet()`):** زر فتح نافذة الأقسام الشاملة.

### ب. نافذة الأقسام المنبثقة (Action Sheet Modal):
- تُفتح فوريّاً عند النقر على "المزيد" أو زر "☰" أو "⋮" في الأعلى.
- تنبثق بسلاسة من أسفل الشاشة وتغطي الشاشة بنمط بطاقات لمسية عالية التباين (2-Column Grid) لعرض كافة أقسام المنظومة مع أيقوناتها.
- تحتوي على زر إغلاق صريح `✖` في الأعلى، وزر اتصال واتساب مباشر في الأسفل، وإمكانية الإغلاق بالنقر على الخلفية المعتمة.

## 3. معايير الأمان وتفادي إنذارات الحماية (Zero-False-Positive Security Rules)

لكي يتم تثبيت ملف الـ APK على أي هاتف بدون ظهور تحذيرات "تطبيق ضار" أو "Blocked by Play Protect" أو إنذارات مكافحة الفيروسات:

1. **🧹 تصفير الأذونات الحساسة (Zero Dangerous Permissions):**
   - يُمنع تماماً طلب أذونات التخزين `READ_EXTERNAL_STORAGE` أو الكاميرا أو الموقع إذا لم تكن ضرورية جوهرياً.
   - الاقتصار على الأذونات القياسية الآمنة فقط:
     ```xml
     <uses-permission android:name="android.permission.INTERNET" />
     <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
     ```
2. **🔒 إيقاف حركة البيانات غير المشفرة:**
   - ضبط `android:usesCleartextTraffic="false"` في المانيفست.
   - تفعيل `android:networkSecurityConfig="@xml/network_security_config"` مع قصر الاتصالات على HTTPS (TLS 1.2+).
   - تعطيل النسخ الاحتياطي غير المشفر `android:allowBackup="false"`.
3. **🛡️ استخدام نواة أندرويد الأصلية الخالصة (Pure Native Core):**
   - استخدام `android.app.Activity` و `android.webkit.WebView` المدمجة مباشرة في نظام أندرويد بدون أي تبعيات Maven خارجية ثقيلة، مما يجعل البناء فائق السرعة، ومستقلاً تماماً بدون إنترنت (100% Offline)، وحجم التطبيق خفيفاً جداً.
4. **🧼 خلو الكود من الدوال المشبوهة:**
   - حظر استخدام `eval()` أو `document.write()`.
   - تعقيم كافة المدخلات وتشفير روابط واتساب عبر `encodeURIComponent`.

## 4. خطة التجميع التلقائي وتصدير ملف الـ APK الجاهز (One-Click Build Engine)

عند بناء التطبيق على نظام Windows:
1. **دعم المسارات العربية:** إضافة `android.overridePathCheck=true` تلقائياً في `gradle.properties`.
2. **الموافقة المسبقة على التراخيص:** إنشاء ملفات `licenses/android-sdk-license` التلقائية لتفادي أي توقف أثناء البناء.
3. **توليد وتصدير ملف الـ APK النهائي:**
   - تنفيذ أمر البناء عبر Gradle: `gradle assembleDebug` أو `gradle assembleRelease`.
   - نسخ ملف الـ `.apk` الناتج مباشرة إلى المجلد الرئيسي للمشروع وإلى مجلد `تطبيق_الهاتف/` بأسماء واضحة (مثل `BaraElSandouq.apk` و `[اسم_المشروع].apk`).
   - إبلاغ المستخدم بمسار الملف الجاهز حتى يتمكن من نقله وتثبيته فوراً دون أي خطوات يدوية إضافية.
