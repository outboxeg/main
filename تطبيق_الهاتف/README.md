# 📱 تطبيق الهاتف الميداني – برة الصندوق (المدرسة الخضراء الذكية) 🌿
## Bara El-Sandouq Standalone Mobile Application & Offline APK Suite

هذا المجلد المخصص (`تطبيق_الهاتف`) يحتوي على الكود الكامل لتطبيق الهاتف المحمول لمشروع **"برة الصندوق – المدرسة الخضراء الذكية"** بمحافظة البحيرة، المنفذ بواسطة **جمعية الإسراء الخيرية لتنمية المجتمع بدمنهور** (إشهار رقم 1124) ولصاحبة الابتكار والملكية الفكرية الأستاذة / **فاطمة عبد المجيد راضي**.

---

### 🚀 كيفية التشغيل والتجربة الفورية:
1. **تجربة التطبيق في المتصفح المحلي:**
   ```bash
   python -m http.server 8080 --directory تطبيق_الهاتف/www
   ```
   ثم فتح: `http://localhost:8080` في المتصفح.

2. **بناء الـ APK عبر Android Studio:**
   - افتح مجلد `تطبيق_الهاتف/android` في برنامج Android Studio.
   - اختر: `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`.
